# Student Grade Calculator

This is my first C# console project.

The program takes 3 grades from the user, calculates the average, and shows the result.

## Features

- Takes 3 grades
- Checks wrong input
- Accepts grades between 0 and 100
- Calculates average
- Shows result

## Results

- Takdir: 85 and higher
- Tesekkur: 70 and higher
- Failed: lower than 70

## Used

- C#
- Console App
- TryParse
- while loop
- if / else

This is a beginner project.
